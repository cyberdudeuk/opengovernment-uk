# Defect register

Internal record, kept in the repository rather than on the portal. Every defect has a guard: a check, a test or a build rule that fails if it comes back.

| ID | What went wrong | Fix and guard |
|---|---|---|
| OR-D1 | Curly and straight apostrophes matched differently (first pilot) | Folding normalises them; check OG-02 includes a case |
| OR-D2 | At 320 pixels every view was wider than the screen (first pilot) | Grids use minmax with min(100%); the page check below measures it |
| OG-D1 | NHS ODS role codes were guessed and returned councils and support units | Codes read from the ODS roles list; the harvest fails if a role returns the wrong description |
| OG-D2 | The Northern Ireland training board borrowed the Great Britain board's Wikidata item when its "(NI)" was stripped | Nation brackets are never stripped for Wikidata lookups, and evidence can't override an explicit nation conflict (OG-04) |
| OG-D3 | Two checks passed their own deliberate breaks (OG-04 looked at any evidence, OG-08 accepted an empty list) | Both rewritten; every check now fails its break |
| OG-D4 | "HM Courts Service" joined "The Court Service", a predecessor body, because HM was ignored | HM is a significant word; the pair goes to a person |
| OG-D5 | The data.gov.uk API caps each page at 25 publishers, so the new harvester kept 25 of 1,045 | Page until a page is empty; the harvest refuses a list under 500 |
| OG-UX-01 | In the first pilot's review, the whole panel looked selected, so you couldn't tell which answer was chosen | Each answer is its own option with a tick, a fill and a Selected label; the choice is also stated in words |
| OG-D6 | Companies House pages nest the name of a person with significant control inside a second element, so the first reader found none | The reader takes the nested text; 45 of 59 companies now show their controller |
| OG-D7 | An office of state (“Lord Chancellor's Department”) was treated as a person's name and withheld | The person rule excludes offices of state; check D-OG4 tests both directions |
| OG-D8 | Companies named after a founder (“Sir … Enterprises Ltd”) were treated as people | A company legal form keeps the name; a bare title and name is still withheld |
| OG-D9 | Non-ministerial departments climbed to the ministry GOV.UK lists as their parent | A non-ministerial department is its own root; check D-OG3 |
| OG-D10 | The footer named the former office | It now names the Government Data Directorate; a check fails the build on the old name |

| OG-D11 | Feed contract download disagreed with the page | Regenerated from the same contract object (D-OG6) |
| OG-D12 | A page constant was read before it was defined, so the page stopped (temporal dead zone) | Definition moved before first use (D-OG7) |
| OG-D13 | Phone-width masthead clipped the title; a long select scrolled the page sideways | Labels visually hidden under 520 px; grid column minmax(0,1fr); selfcheck 'no sideways scrolling' |

| OG-D17 | The trends personal-data check matched "Chair" inside a body name ("Law Commission, with the exception of the Chair") | Checks field names, not body names (D-OG12) |

| OG-D19 | The "Nov2020" public bodies workbook in SharePoint was built on the 2019 edition | Workbook not used as data; the official 2020 edition is the baseline; the comparison is recorded in the trends document |
| OG-D20 | Two requirements shared the ID OG-R20 after new requirements were added | Renumbered OG-R21 to OG-R26; the portal build stops on any duplicate ID (D-OG15) |
| OG-D21 | The legislature rule matched the bare word "parliamentary", placing boundary commissions and an advisory panel in the legislature | Explicit names only; the Parliamentary Boundary Commission for England is a known answer in the executive (D-OG16) |
| OG-D22 | The nations known-answer check skipped answers it could not find, so it passed while the Scottish Parliament was absent | A known answer must be found; a second negative test removes an apex and must fail (D-OG17) |
| OG-D23 | The register holds no record for the legislatures themselves or Scotland's supreme courts | Each branch's apex is stated from its founding legislation, linked and labelled as not yet a register record; adding them as records is planned |

| OG-D25 | A register's location code outranked governance evidence: Velindre NHS Trust shown in England, the Planning Inspectorate in Wales | Governance (who a body answers to, who sponsors it) and the body's own statement outrank a register's code; both are known answers |
| OG-D26 | A founding Act's whole extent placed councils in Great Britain (Local Government Act 1972) | Statute extent is an upper bound and is never applied to councils; Three Rivers District Council is a known answer |
| OG-D27 | Reading a body's own page took only the first nation of a list ("in England, Scotland and Wales" read as England) | Lists are read whole; the Central Arbitration Committee and Civil Nuclear Constabulary are known answers |
| OG-D28 | Councils written in legal-name forms ("Borough of …", "… Metropolitan District Council", "City and County of …") did not match ONS names | Legal-name forms handled; Bradford and Swansea are known answers |

| OG-D33 | Every disagreement between sources was shown, including ones the stated rules already settle | Each is triangulated against the published order of sources, the chain itself (nested parents), joint listings and the count of independent sources; only contested ones are shown, and an independent check re-verifies every resolution |
| OG-D34 | Internal apps were listed as consumers of the feed on the public site | Only apps with a live public portal and a public repository are listed, each with both links; the build stops if a listed public app is missing |

| OG-D36 | The open standards list was out of date (BODS, JSON-LD, OWL, GSS, COFOG and language tags missing; one licence stated for all files) | Rebuilt with every standard in use, its status and a deep link; ISO 3166-2 nation codes added to the data |

| OG-D39 | The portal said mayors are elected by first past the post (Elections Act 2022), which the English Devolution and Community Empowerment Act 2026 reversed | Mayoral and London rules now say the supplementary vote returns after May 2026, with the Act and the government's commencement statement linked; council rules note the end of the committee system |
| OG-D40 | Screen-reader-only text ("opens in a new tab") showed on screen because the portal had no .sr-only class | Class added; the build stops if a page uses it without defining it |

| OG-D46 | gov.im answered "Error Page" and later "Request Rejected" with HTTP 200, which would have counted as a confirming website | A website confirms a body only with status 200, a matching address and a page title that is not an error page; it fails closed.
