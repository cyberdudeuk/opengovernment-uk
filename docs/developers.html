    Connect

    The published files are the API. Read them with a plain HTTPS GET: no key, no sign-in, and any website can read them from the browser (the host sends Access-Control-Allow-Origin: *). Send If-None-Match with the ETag you last saw to get a quick 304 Not Modified when nothing changed. Base address: https://cyberdudeuk.github.io/opengovernment-uk/.

    Harvest

    1. Start from the catalogue. catalogue.jsonld is W3C DCAT 3: every dataset, its download address, format, licence and the standard it follows. CKAN, data.gov.uk-style harvesters and most catalogues read it.
    2. Or follow the sitemap. sitemap.xml lists every page and file; robots.txt allows all crawlers. Every page carries a schema.org Dataset in its head for dataset search engines.
    3. Describe the tables. datapackage.json (Frictionless) and CSVW metadata give column names, types and keys.
    4. Keep in step cheaply. Re-read on your own schedule with conditional requests (ETag or Last-Modified). alerts.json lists the latest changes; provenance.jsonld lists every source with its fingerprint, so you can tell what changed.
    5. Know how fresh it is. source-status.json says when each source was read and what could not be read. The register is rebuilt on demand, not on a fixed schedule.
    6. Keep the identifiers. Each body is https://cyberdudeuk.github.io/opengovernment-uk/id/<register key>, for example id/government-organisation:D9. They are stable names; they do not yet open a page of their own.

    Where this export departs from a published mapping

    FollowTheMoney only lets an Ownership point at a company, so the UK's shares in international financial institutions are a Membership whose description gives the share of votes. Public-sector test case 20 sets this out for converter authors.

    MCP and agents

    A Model Context Protocol connector gives any MCP client (Claude, coding assistants, your own agent) cited answers from the published files. It runs on your own computer, needs no account and costs nothing; it is read-only and reads only the published files.

    ToolWhat it answers
    search_bodiesFind public bodies by name or register key. Returns key, name, family and whether it is open.
    get_bodyOne body's record: kind, status, nations, parents, dates, website, worked-out purpose and activity, identifiers.
    who_answersWho a body answers to in the end, and the chain of links, each with its relation and source.
    uk_and_countryThe UK's trade agreement in effect, tax treaty, Commonwealth membership and treaty count with one country.
    source_statusWhen each source was read, whether it is current, and what could not be read and why.
    crosswalkHow a register field maps to BODS, FollowTheMoney, ORG and schema.org, Wikidata, org-id and OpenCorporates.
    list_datasetsEvery published file with its title, format and licence, from the DCAT catalogue.

    Set it up

    1. Get the code: clone the repository (opens in a new tab) or download integrations/mcp (opens in a new tab).
    2. Install its one dependency: 
      pip install -r integrations/mcp/requirements.txt
    3. Add it to your client. Claude Code:
      claude mcp add opengovernment-uk -- python integrations/mcp/server.py
      Claude Desktop and other clients that use a JSON settings file:
      {
  "mcpServers": {
    "opengovernment-uk": {
      "command": "python",
      "args": [
        "/path/to/opengovernment-uk/integrations/mcp/server.py"
      ]
    }
  }
}
    4. Optional: set OGUK_DATA to a local copy of docs/ to work offline.

    Test and validate

    • Public-sector BODS test cases (opens in a new tab): a state's shares in an international body; control by law; sponsorship in an extension. Each has a statement of correct handling, in the shared fixture pack's layout.
    • BODS: the file is checked against the official schema and Open Ownership's lib-cove-bods on every build:
      pip install libcovebods
libcovebods jsv bods-0.4.json && libcovebods pv bods-0.4.json
    • FollowTheMoney: every entity is checked against FollowTheMoney's own compiled model (tools/ftm_export.py (opens in a new tab)).
    • Agent answers: tools/agent_evals.py (opens in a new tab) answers the known questions from the published files.
    • Everything: the checks workflow (opens in a new tab) runs every check, each with a test that proves it fails when it should.
