## Technical requirements

| ID | Requirement |
|---|---|
| T1 | Static site only (GitHub Pages); no server, no sign-in, no cookies |
| T2 | Python 3.11+; dependencies pinned in requirements.txt; GitHub Actions pinned to commit SHAs |
| T3 | Every build fails closed: a failed check stops publication |
| T4 | Least privilege: workflows read-only; no secrets in the repository |
| T5 | Output escaped in the page; safe loaders only; no evaluation of input |
| T6 | Open formats: JSON, CSV with CSVW, JSON-LD (ORG, DCAT, SKOS), BODS 0.4 |
| T7 | Accessibility: WCAG 2.2 AA; works at 320 px and 400% zoom; light and dark |
| T8 | No personal data in any output; files naming people are fetched, not redistributed |
